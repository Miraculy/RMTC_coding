## 文献提供的依据及不能照搬的部分

- [Thayer 与 Carpin，2021，An Adaptive Method for the Stochastic Orienteering Problem](https://escholarship.org/uc/item/2888656n)：研究随机旅行代价下根据实际到达时间调整奖励节点次序。本项目可借鉴“执行后分支”的思路；其旅行分布及预算约束并不等于四车抢一次性资源。
- [Endo 等，2026，OP with Uncertain Time-Varying Rewards](https://arxiv.org/html/2608.18672v1)：比较单步、离线整条路线和在线重规划，强调奖励应按到达时刻估计。该文采用奖励转移模型；本项目资源固定、会被对手永久取走，不能套用其转移矩阵或理论保证。
- [Qian 等，2024，Adaptive Probabilistic Planning](https://arxiv.org/html/2409.05545v1)：用执行观测更新不确定代价并重规划，支持将实际失败与预计到达联系起来。其 UAV 能耗与任务成功率不构成本项目增分证据。
- [Chandra 等，2025，Social Mini-Games](https://www.cs.utexas.edu/~pstone/Papers/bib2html/b2hd-smg.html)：研究非协作、无通信、部分可观测多机器人中的持续停滞。这里可借鉴把“安全但不前进”单独处理；连续控制屏障函数不能直接解决格点争抢后的资源归属。

## 全链路判断与实施次序

从上轮归档去重选取八张地图各一场默认无事件比赛，分析四车各自日志：8 场、32 份本车记录、16000 个决策。来自三个冻结构建，只用于描述机制，不合并成一个策略的胜率。

| 环节 | 现有证据 | 对改进方向的约束 |
| --- | --- | --- |
| 输入与提交 | 上轮原始场有两条末期回执类型异常；合格筛选场逐 Tick 完整 | 本地规划耗时不能代替端到端提交；新实验继续核查实际回执 |

| 选目标 | 已有三站资源前瞻、竞争折扣、任务边际分和回程启发式 | “加资源前瞻”并非全新方案；提高高值权重、取消回程折扣已有负结果 |
| 到达与进入 | 前 60 Tick 的 803 个资源目标决策中，119 个移动因阻塞失败，集中在一张图的争格过程 | 这些是连续失败次数，不是 119 个独立可追回资源；静态可达没有保证实际进入 |
| 执行反馈 | 旧 Planner 未利用 last_action.error；移动计划仍给假定终点奖励，未进入格也不会增加该格访问惩罚 | 同一失败动作可以无限重复，是证据最清楚的闭环缺口 |
| 采集与计分 | 八场最终全图各取得 200 资源；R120 前每 10 资源计 2.5 分，任务分另计 | 提升的是本车份额，不能要求四辆对称策略同时达到 R120；解除堵塞不等于本车多拿资源 |

优先级及边界：

1. **失败争格后采集已知备选**：先处理有真实失败回执、另有当前可见资源的局面。因果链短，能逐步核对发现、改道、实际进入、资源增量与终局。此次唯一实施方案。
2. **资源链的到达时可获得性**：在已存在的 `race_aware_resources` 基础上，研究互斥对手目标/动作分支，把争格失败与改道纳入后续路线，分支内计算资源封顶，防止重复折扣。不是简单再加 BFS 或 ETA。须先验证可挽回机会覆盖，并防止已有沿途采集的反例重现。未实施、未自测，等待批准。
3. **更早发现可赢资源的开局路线**：研究路线带来的首次发现时刻和发现后余量，保留已知资源链的机会成本。竞争探索、延后追击、信息首步已有负结果，不能直接重开。未实施、未自测，等待批准。
4. **事件改变资源窗口时的提前执行**：已有默认解释曾在定向场增分，但正常事件收益不稳定；不能当作新方案已成功。此次无事件测试不能评估它。未实施、未自测，等待批准。

## 方案一：完整机制

独立参数 `resource_blocked_recovery`，core 与 node 初始默认均为 false。其余既有参数保持原值。第一阶段、第二阶段前五分之一之后、已解析事件/效果、启用中的 forecast，以及其他资源路线实验组合继续原处理。

触发条件为本车连续两次对相邻资源的实际提交与下一帧回执对应：session/Tick 连续、提交和回执均为 MOVE、error=E_BLOCKED、未移动且位置未变。该资源仍然可见、未被占据，也有可见活车相邻；不将失败解释成资源消失或墙体。原目标仍是这个资源才开始改道。两次是有待检验的启发阈值，不是对手意图的事实。

备选必须本 Tick 可见。仅在当前视野内已知可走且未占用的格子上搜索，临时避开争格点，路线最多两倍视野半径；必须比所有当前可见活车的曼哈顿移动下界更短。未知对手、未来复活和未来攻击仍不可预测，不声称必然抢赢。第一步不得增加对当前可见普通火线的暴露，当前保守伤害不得预测移动前阵亡；即时可收尾攻击仍优先沿用原处理。

用剩余资源分和本车公开任务进度计算备选价值。选定后保留至最初路径步数加两 Tick 的期限，期限不逐帧延期；每帧重新确认资源、已知路线、可见竞争优势和危险。不能只挪一步就被原相邻目标重新吸回。新阻塞、缺帧、资源消失、对手先到、危险或期限不足都撤销承诺。动作层仍比较移动、攻击、防御，未强制覆盖战斗。

只有下一感知中的位置和资源增量能确认采集。日志 `resource_recovery_evaluation` 将 started/continued/cancelled/no_alternative、失败次数、路径、可见对手下界、最终动作分开保存，不将计划写成事实。

没有可赢备选时，此方案保留原行为，因此不声称解决全部争格。尤其上轮 `resource_fresh_returns` 导致的三车争高值反例不能仅靠本方案保证由本车获得高值。
