## 当前工作目标

在只使用本车合法感知、历史及公开信息的前提下，先修正事件身份和互斥战斗动作的建模问题，再以开局首次高价值资源为重点做独立策略实验；采用规则场景、跨图完整配对和不同对手验证收益。每次只改变一个机制，不把局部指标或同分当成成功。默认策略只有在足够证据支持后才推广。

先后顺序：事件修正身份 → purity互斥估值 → 开局高价值资源机会诊断及实验 → 辣椒/联合伤害结算 → 队列、有效资源门控与死亡机会成本。概率预测、统一时间展开和全局状态机待前面的机制可靠后再做，避免同时引入多个自由参数。

## 对原六个新方向及可选组合的判断

1. 信念分布是单点预测的扩展，不是只把硬集合改成几个常数概率。与robust最坏分支及safe_progress_moves应使用同一互斥动作解释，不能重复扣风险。
2. 24×24×16的位置时间图仅9216个节点，但加入HP、已收资源和敌人分布后远大于此；先局部移动/已知事件，暂不重写整个Planner。
3. 死亡机会成本有价值，但“60D+3等待+2保护”不能直接相加。以权威D和可行动的复活帧为准；不能将储备项与同一死亡损失重复计费，返程只做不确定估计。
4. 资源消失意图值得离线诊断。只有连续可见帧、资源消失且可明确归属时才能积累保守观察；仅有某车资源下界不能证明其领先，更不能当成总分排名。
5. 预算器不是自动优于启发式。R/D/任务缺口不能忽略剩余可达机会；先用作诊断，避免再次普遍抬高探索和任务权重。
6. 规则场景与多类对手最有直接验证价值。“对手联盟”是独立脚本对手集合，四车不共享私有信息、不协同；同一程序、同一对手配置内配对。
7. 事件组合先验证结算。任何控制区域方案仅使用公告及已知地图，不把隐藏资源分布或未来敌人动作当输入。

## 验收与当前实施边界

- 正确性：事件修正不误删独立事件，不接纳未知/过期版本引用，失败原子回滚；模型输出仍负责语义判断，本地不解析公告语义。
- 策略：新机制默认关闭。无事件默认完整回归应保持；事件机制须先有实际触发与正确语义证据，再比较500Tick总分、资源、任务、D及排名。
- 推广前至少4图×4席位16对，并保留未调参地图、不同对手以及全部退步。规则合成场景和短冒烟不冒充最终分收益。
- 复用现有受控测试工具和隔离ROS域，测试配置仅驱动裁判，参赛端不读取。沙盒副本的122项测试是输入文档报告，未在原目录复验前不当作本轮成果。
