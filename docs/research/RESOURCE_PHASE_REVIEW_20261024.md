# 资源分阶段实验：2026-10-24

本轮按用户提出的“前60–100 Tick争取高价值资源和R120，之后转向任务、D500、同分与防守”实施独立实验。结论：阶段划分值得保留，但这版开局加权降低了资源和总分，满额切换也没有改善最终完成率；不推广到正式默认。

原暂停目标仍在 `GOAL_ARCHIVE_2026-10-23.md`，没有恢复或标完成。本轮未调用外部模型，未修改裁判、协议、密钥或正式参赛源码。开发比赛中的四车各自仅使用本车感知、历史和公开话题，日志事后分析不回传控制器。

前两个开关有独立本车诊断 `resource_phase_evaluation`。局部安静不代表全程安全，未知格可通行仍只是路径假设，未写回为地形/资源真值。没有把“已看到”当成“必能抢到”，没有读取敌人私有任务、地图配置或裁判全局轨迹来控制车辆。

本轮没有组合开启三个开关，没有修改伤害/死亡公式，也没有额外实现“保证D始终不低于500”的逻辑。任务按本场公开类型和自身完成ID处理，不能假定正式比赛永远是固定的三个任务。

## R120切换的实际覆盖与正反例

主组仅1/16焦点达到R120，不能把其余15个未触发案例当成大量安全性证据。唯一触发的 `interior67153 C` 两侧均Tick38到120；切换后到达任务298→55 Tick，死亡11→6次，D1160→775，最终60分/第一不变。其47个存活决策窗口跳过了至少一个纯资源目标。

## 对用户方案的修订建议（下一步，尚未实现）

1. 将60–100 Tick作为有限资源窗口和重新评估点，R120作为资源分收益上限，而不是完成任务必须等待的门槛。任务需要的高价值/普通资源从开局就应计入路线；顺路到达任务可以提前做。
2. 已知低风险采集链优先于无证据的远探索。不能只按“普通资源超过两步”压低价值；三至五步也可能是当前最可靠的收益。高价值优先须同时比较到达代价、可见竞争和是否实际推进任务。
3. 未知探索只提供发现机会，不能直接赋予保证可兑现的资源收益。等长多看视野已测无收益，应先定位能改变争夺结果的发现窗口，再扩大实现。
4. 满额后取消纯资源分收益，保留任务所需采集；同分资源和剥夺必须与路程/风险比较，不能假装知道敌人任务进度或领先情况。
5. 任务路线应与D缺口、剩余时间、已知/未知路段和退出条件联合比较。本轮远任务出发时无敌仍失败，短期局部安全不是长期可执行性证明。下一轮优先针对“满额但D未封顶、远任务可推迟”这一类情形做独立机制实验，而不是盲开所有开关。

这些修订仍需独立配对证据。标准练习地图总资源200，四车每车120需480；没有出生均衡保证，其他车还可能先拿任务关键资源，因此不能承诺每图R120且三任务全部完成。
