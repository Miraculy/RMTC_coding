## 代码实现

实现位于 `experiments/stage1-dense-20261024/src/rmtc_bot/src/stage1_planner.cpp`。核心和节点的 `stage1_resource_route` 均默认false；只有第一阶段且显式启用才进入新模块。

1. 对记忆障碍做BFS，用真实绕行距离替代直线距离估计。可兑现的资源路线仅使用已经实际观察过的可通行格；资源记忆不因单车无竞争下的时间衰减而丢失。
2. 在剩余100−tick预算内对最多16个已知资源做子集DP，先最大资源价值、再最短路程。最近邻和2-opt提供可行初始解；20ms求解上限到达时保留可行解，不把未完成求解说成最优。
3. 用公开200总资源、本车已采值、已知未采资源计算未知价值。未知格只用于乐观距离与收益上界，不被记成观察事实。将未知资源放入可以“免费跨未知区域”的虚拟节点，会高估实际可得收益，从而适合做上界，不能用作执行路线。
4. 复制旧控制器和本车World，预测其下一整个视野都已知的前缀。一旦需要新的观察就停止预测；不猜测未知障碍或资源。对这个前缀之后的所有可能延续计算乐观收益上界。
5. 只有已确认可执行的资源路线与该基线上界相差不超过10资源价值（2分）时才切换。切换后保留已验证的路线，新路线必须维持其剩余价值，避免下一Tick又把已经预留的收尾路线推翻。第一步在等短路径中优先新视野。
6. 敌车记忆、事件、资源数量超过支持范围时回退原控制器；第二阶段完全不进入这一分支。

以上约束针对单车、静态地图、公开200资源总量的标准第一阶段。不存在读取种子、固定地图坐标表或oracle文件的策略分支。

## 为什么还不能满分

原15图首次有足够依据采用新路线的Tick中位数为67，范围44–94。此前通常仍沿用原探索策略。大量可节省的“探索→绕回采集”已经发生，后期再把已知资源串成最短路线，也无法补回这段路程。

例如seed20261024：原版30分，稳定候选34分，较激进的乐观候选可以40分。稳定候选到Tick54才首次满足切换条件，之后保留了可兑现的资源路线；此时早期绕行已经限制了满分机会。乐观候选虽然此图满分，却在其他开发图上最多掉14分，不能只据这一张图替换正式算法。

![实际裁判路线对比](../experiments/stage1-dense-20261024/report-assets/route-comparison-20261024.png)

三张−2分的新图体现了当前上界策略的实际代价：首次切换时可兑现的剩余价值分别为30、30、10，而对旧策略的上界分别为40、40、20；新路线兑现了自身承诺，但旧策略最终恰好多拿到那10价值。所有失败均保留在 `regression-diagnostics.json`，没有删除或替换这些地图。

下一步应优先研究：保留可兑现资源价值的前提下，是否还能先沿旧策略多走一步取得信息或顺路资源；更早把资源链与探索出口联合安排。继续调单个资源/探索权重，或者在观察不足时无条件追资源，均缺少本轮证据支持。

## 正确性、合法性与耗时

- 230场、23,000条一阶段决策，230份实际参数审计、230份接口审计；0非法动作、0感知拒绝、0缺Tick、0回执错配，包含最后Tick99。1,992个已承诺路线状态均通过剩余步数和终局价值兑现检查，未触发求解超时。
- 各场P95中的最大值10.912ms，单次最大11.388ms，均低于25/50ms门槛。
- 程序只订阅本车感知与公开任务、事件文本、注册信息。配置、种子、完整状态和全知oracle只留在测试/分析端；测试时本车日志目录使用不含种子的临时路径。四个并发一阶段工作进程为四场隔离单车比赛。
- 129项核心测试、14项HTTP测试全部通过，2个CTest目标通过；10项工具测试覆盖地图密度/连通性、外车感知订阅、参数不生效、丢Tick、最后回执、数据哈希、路线承诺失兑现等情况。核心新增的独立枚举测试核对最优价值与基线前缀后的收益上界，另验证新资源发现后仍保留原路线价值。
- 第二阶段使用正式9945…与候选034c…，两图各500Tick、同场四个独立控制器，共4,000对决策（8,000条原记录）逐字段等价；仅排除场次编号、耗时和新增诊断字段。16份合法接口，回执完整，0非法/拒绝。该旧测试驱动没有运行时参数dump，启用开关的证据为冻结启动参数、节点声明和阶段隔离单测，不能写成16份实际参数dump。
- 一次对照尝试在ROS接口发现检查处、比赛恢复计时前失败，0记录、无得分结果。原始失败manifest与日志保留；仅续跑33个缺失结果，没有重跑197个成功结果，程序、裁判驱动和地图哈希均未变。当前工具已修复为等待完整接口元数据并先保存快照，另用seed7777/40%的一场工具冒烟确认100Tick/回执完整；该场不计入上表。
