# 本轮工作总结：二阶段公平资源条件下的复评与优化

规则范围：本报告记录收到v1.2补充说明前完成的现有练习裁判实验，不冒称v1.2事件实战验收。

2026-10-26。**现有方案尚无“绝大部分条件明显提高资源分”的证据；本轮新增候选也未达推广标准，正式程序保持不变。**

## 这次完成了什么

1. 按用户确认的“出生区域资源数量或总价值接近”，构造数量公平、价值公平及随机三类开发分布，共6张固定地图，轮换四个焦点席位；公平不被解读成镜像或隐藏资源坐标已知。
2. 核实根目录源码与已安装二阶段程序的版本差异，从历史提交恢复独立二阶段工作副本，保留正式程序及全部一阶段工作。
3. 复评默认版B0与已交付的恢复版B1，分析合法本车日志中的发现、选择、到达、采集和得分链路。
4. 诊断已有精确资源路径开关；实现并冻结“按发现后回收机会选择观察点”的完整候选，运行全部24场闭环对照。
5. 保留所有失败、中断及排除记录；补齐无效配对，完成严格审计、源码补丁和离线复核工具。

## 得到了什么结果

| 方案 | 公平组结果 | 决定 |
|---|---|---|
| 原恢复机制B1相对B0 | 16组均52.5R，全部24场行动和最终结果相同，恢复有效启动0次 | 仍仅有历史局部收益证据 |
| 已有精确资源间路径选项 | 12,000帧合法重放，动作／目标／目标原因差异0 | 不当作新比赛或增分证据 |
| 新回收机会探索候选 | 平均R 52.5→50；资源分 13.125→12.5；增／平／降 1／11／4 | 未通过，不推广 |

新候选公平组平均总分 40.5562→39.675，确定前二 9/16→7/16；随机组平均资源 50→50。公平组资源变化的地图聚类95%区间为 [-5, 0.625]，仅作小规模开发统计。

局部正例 count61001-A 为60→70R、第二→第一；反例 count61002-C 为70→50R、第一→第三。后者改变探索方向后，整场未见旧版后来取到的两枚普通资源。**回收距离启发式能改变探索，但没有充分解决全程覆盖次序。**

## 自测与证据边界

- 140项核心测试、14项HTTP测试及两个CTest目标通过；13项工具检查通过。
- B0、B1、候选各24场，共72场、144,000决策及回执；接口、实际参数、末Tick499回执和动作方向全部核查，选入场0非法、0拒绝、0缺帧、0未解释回执错配。
- 最大单车本地P95 9.214ms。主矩阵100ms，count61001-B三版本均500ms；初始50ms失败场、100ms异常配对和环境中断均单独保留。
- 本轮无真实AI、无事件，都是角落出生开发图；没有完整正式500ms全矩阵或未见集确认，不能宣称正式资格或跨分布稳定满分。全场200R，公平本身不能保证某车达到120R。
