# 二阶段 v2.4：天使恩泽的条件利用

日期：2026-10-29。在 v2.3 基础上合入天使恩泽实验优化。

## 改动
- `PlannerConfig` 新增 `angel_value`，默认 false；`final.yaml` 设为 true；
- 仅当**已知资源为空**时才启用增强天使逻辑，资源获取优先级不变；
- 只在缺失 HP 足以抵消路程时才绕路：

  `missing_hp >= 2 × travel + 4`

- 支持提前到天使点旁等待、事件开始后进入；
- 保留原有 `hp<80` 的天使报价，用于资源尚未清空时；
- 不改变资源、任务和战斗逻辑。

## 实验依据
- S03：HP=60、距点约 6 格，条件满足，Tick 73 转向 heal，76 进点，HP 60→100；最终 45.0 第一；
- S04：HP=80、距点约 12 格，条件不满足，不绕路；最终 42.5 第一；对比无距离约束版本曾绕路回血后掉到第二（D 43.2 反超）；
- T02：HP=80、距点远，守卫跳过，最终 42.5 第一；DeepSeek 17/17 成功/应用。
