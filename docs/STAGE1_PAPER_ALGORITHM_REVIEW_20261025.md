## 3. 建议修正的关键细节

### 3.1 观测目标不应只允许传统前沿格

赛事视野为不被障碍遮挡的方形。当前已见方形的边缘才邻接未知，但只移动一步就可能看到新的整条带状区域，不必一路走到边缘再获取信息。

候选应从所有“已知可达、预计视野有新增”的格子中筛选；传统frontier可以作为聚类参考。分组同时看新视野掩码重叠和已知通行成本，不能只看直线距离：隔墙两点可能很近却需要大绕行。每簇保留便宜观察点、较大覆盖点、较好后续出口等非支配代表；这是待试的工程设计，没有现成满分保证。

区域收集宏动作也应保留入口/出口条件。不能把一个区简化成“总资源/到入口距离”，忽略区内清扫和离开的路程。

### 3.2 “已知图不可达”不等于真实不可达

`d_safe`只经过已观察空地，给出可执行路径；如果无路，只说明尚未确认通路。`d_relaxed`将未知暂作可走，给出距离下界；不是实际保证。`d_estimated`才加入未知绕行预测。

资源当前没有safe路径时，仍需留在记忆中，并允许以获得通路信息的观察点为候选。保证收益只计safe路线，预测距离单独标注。单车静态阶段，一条完全由已观察空地构成的路线不会因为后来看到另一面墙而突然变成碰墙路线。

### 3.3 兑现概率要表达“共同预算内真正取到”

附件明确承认均匀资源分布是假设，这一点正确。但`p_reachable * p_budget`不能随意当独立概率相乘；预算余量本身取决于绕行和后续采集顺序。即使分别估计每个资源都能来得及拿，也不代表所有资源共同执行时都来得及。

更合适的评价对象是：同一可执行后续策略，在同一剩余预算下，到结束时新增采集多少R。首次发现时间、发现后额外取回步数、取回造成的原资源机会损失，应分别核对。多观察点的新视野取并集；路途中顺便采到的资源只计一次；取回时间和移动时间进入同一预算。

当前joint的平均取回距离是简化几何估计，隔墙资源可能远超此成本。subgoal虽做整图模拟，但简化后续策略并非原控制器，仍会估错。

### 3.4 最终目标是100Tick资源价值，时间主要作为约束

附件`R_guaranteed + lambda*R_explore - mu*C - eta*SwitchCost`可作启发式，但不是原比赛目标。工程反例：终局两条可行收尾路线A拿180R/走90步，B拿160R/走40步；若没有其他后续收益项而取`mu=.5`，评分135与140会选B，最终资源更少。

因此优先评价完整剩余预算下的最终可采R；用耗时作可行性约束、同收益择短或计算剪枝。不要把已用于预算的每步再无条件大幅扣分。探索能否取回应直接受剩余预算影响，附件固定随Tick下降的lambda仅作消融候选，不能预先认定有效。

这里并不建议总是把known收益放在exploration之前：前几轮已经证明，强制先追已见普通资源也会漏掉高价值区域。

### 3.5 Beam应保留全局可行收尾，宏动作应可中断

若尝试宽16、深4，状态至少包含位置、已花Tick、已采资源掩码、新视野并集、首段目标以及可执行收尾值。资源间边沿途采集和视野一起更新。不要仅因同位置/同时间就合并观察历史不同的状态。

已有已知资源DP/当前有效路线应始终作为种子和候选。搜索到深度4时还要评价余下已知资源的可行收尾，避免把“前四个资源效率高”误当作100Tick总收益高。

附件“最多一个前沿目标”值得试：先比较已知资源序列，允许插入一个已观察空地中的观测目标，到该目标或途中得到关键新信息后再规划。这比一次假定多个尚未确认区域可串起来更容易核对。宏动作不是连续锁死若干Tick；新资源、通路变化或预算不足应触发重新评价。

### 3.6 反循环应区分必要回程

5–10Tick没采到东西是诊断信号，长走廊上的必要转场不应强制换目标。循环应结合位置重复、知识是否变化、资源集合、目标与最短剩余步数是否推进判断。切换时记录改道理由与预计增益，区分正常完成子目标和无收益反复改选。

只在区域完整观测、出入口与资源状态有证据时标空支路。已知部分图上的桥不等于真实地图死胡同。每Tick更新负面信息：新增空地没有资源，会降低该方向剩余资源机会，即使没有新墙或新资源。

## 4. 文献查阅对当前失败的新解释

以下是将文献与本项目对照后的推断，不是这些论文对RMTC给出的实验结论。

1. **先校准参考策略。** [Bhattacharya等，RA-L 2020](https://arxiv.org/html/2002.04175)第III节的rollout以已知基础策略的后续值为起点，并明确终端近似误差会影响改进界。当前subgoal创建新`Planner`作参考首步，后续用简化策略模拟，没有完整保留原控制器目标记忆；应先做合法历史状态复制与独立重放核对。论文的无限时域折扣界不能直接当100Tick保底。
2. **8张场景不是风险保证。** [DESPOT，JAIR 2017](https://arxiv.org/html/1609.03250)§3、§5.2解释有限场景过拟合，并以策略规模正则化减轻问题。它支持检查样本选择偏差、独立评估候选的方向；不支持把本项目最大两次短缺均值叫作经过校准的CVaR或置信下界。
3. **同模型比较必要，覆盖真实不确定性也必要。** [Ghavamzadeh等，NeurIPS 2016](https://papers.neurips.cc/paper_files/paper/2016/file/9a3d458322d70046f63dfd8b0153ece4-Paper.pdf)§3比较同一不确定模型中的候选与基线；其安全前提包括真实模型属于不确定集合，求解还存在难度。我们已有同场景配对，但未证明样本集合覆盖正式地图，10R门槛不能保证实战最多退2分。[SPIBB，ICML 2019](https://proceedings.mlr.press/v97/laroche19a.html)的少证据状态回退思想可借鉴，MDP数据覆盖保证不能直接移植到整个未知地图状态。
4. **存在可核对的生成分布差异。** 本地`tools/stage1_eval.py:18`生成开发图时，只有保持全部空地连通才接受新障碍；subgoal`:225`逐未知格独立采墙，没有相同连通条件。因此样本可出现开发图生成器不产生的通路结构，且资源可能放进样本中不可达的区域。这是实现事实，但尚未通过消融确定其对−12反例的贡献。正式规则未提供全图连通保证，不能直接把开发生成约束写成正式已知事实；应比较多种先验并检查失配。
5. **减少重算有研究依据，不能丢弃真实观测。** [VOIMCP，ICAPS 2026，2026-06-08发表](https://ojs.aaai.org/index.php/ICAPS/article/view/42824)，[方法全文](https://arxiv.org/html/2604.01434v1)，按信息是否值得推演来选择展开未来观测分支。[Limited Adaptivity，AISTATS 2024](https://proceedings.mlr.press/v238/tan24a.html)研究少轮自适应的信息覆盖代价。可以借鉴“关键事件重算、其余保留路线”；它们优化目标/先验与比赛不同，不能据此固定每5Tick才感知或把新空地忽略。
6. **观察收益前移可作受控候选。** [FIG-OP，2022](https://arxiv.org/html/2203.06316)§III保留长程orienteering，同时偏好较早获得信息，并讨论振荡。我们可以在同等可采收益下比较更早获得关键新视野的路径；其覆盖率结果不等于RMTC采集分增长。

## 5. 推荐的下一轮顺序

先保存当前冻结版与全部失败，不恢复未通过版本为默认。以下均是建议，尚未实现或新增实测：

1. 用当前本车日志补齐失分分类，并对预测取回成本、参考后续值做离线校准；原15的已见未采与新研究版的漏区域分别分析。模型误差未明前不继续扩大改道权限。
2. 只改变观测候选：方形视野掩码去重＋已知通行成本聚类；保留已有候选/路线作对照，观察是否错误删掉关键入口。避免同时重写收益与搜索器。
3. 尝试“多已知资源＋最多一次观察”的预算Beam，保留已知DP和旧有效路线，以完整预算终局R评价。首轮只用现有开发图，不查看3000系列。
4. 单独加入剩余预算条件下的资源取回估计，与均匀视野收益、当前8场景模型分别消融；同时核对候选选择数据与校准数据的重复使用，不把事后调参当验证。
5. 再试切换迟滞、关键事件重算。比较最终R与尾部稳定性，不能只看目标切换/重复移动下降。

正式原版、联合v17、本轮候选至少三组对照。沿用原15均分+2且增加满分、各密度组均分/P10/最低分/单图退步限制、接口/回执完整及P95≤25ms/max≤50ms；先通过开发筛选，再冻结并使用未见确认图。第二阶段完整回归仍是推广前要求。全知≤100步只是物理可满分的必要条件，不证明未知图在线策略必然能满分。
