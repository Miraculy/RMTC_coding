# 死亡、复活与战斗后推进价值复盘

记录日期：2026-10-23。基线为dc197c2f...默认策略。目标是在只使用本车合法感知、历史与公开信息的条件下，提高最终分数和第一次数；正式仍只控制一车。

## 用户补充规则及信息边界

最近合法复活格以初始出生点为原点，曼哈顿距离逐层展开，按上→右→下→左邻格搜索顺序确定同层次序；障碍只排除落点，不阻断搜索，资源格允许。多车同Tick复活按A→B→C→D依次更新占位。完整记录见RULES_V1_1.md。这说明复活代价必须考虑等待和返程，而不是只扣60点D或假定在死亡位置附近复活。

当前每帧坐标来自本车self.position。只有本场Tick0记录初始spawn；备用落点不覆盖它，漏初始帧时保持未知。未来占位、隐藏障碍及对手出生点没有因此变成已知。后续如生成落点候选，需要保持这一不确定性，不能向World写入假想的真实位置。

## 本车历史的实际证据

取上一轮当前默认对手八图32个焦点车基线日志：finish-explore-control-known/fresh/held-one/held-two四个冻结批次。只读各车自己的decision记录，没有读取裁判轨迹、隐藏地图或对手私有感知。175次从HP>0到HP=0的变化中，17次发生在前100Tick；174次后续记录到恢复存活，均在死亡动作Tick后的第4个Tick，实际位置都回到本车初始出生点。另1次死亡接近比赛结束，没有后续存活帧。该样本没有备用落点，不能用于声称已验证并发或阻挡时的搜索次序。

有8次死亡时仍存在已知资源，3次动作选择的是前往公开坐标任务的移动。3次都发生在interior64811 D，Tick189/206/222：本车HP10，分别在(6,5)/(5,6)/(4,5)，任务目标(4,6)，当前可见普通敌车处于射程内且最近状态不是防御；下一帧本车均阵亡，移动没有完成，随后等待并从初始点(8,3)重新出发。坐标仅用于复核，不能成为策略条件。

这个发现不证明能避免这些死亡，也不证明对手下一Tick必定开火；它揭示了当前估值在自己的来火模型下不一致：已预测战斗先致死，却仍给随后执行不了的移动、任务距离缩短和入点效果计入收益。

## 首个独立实验

新增survival_conditioned_progress=false，core与ROS参数默认同步关闭，评估入口只允许白名单参数。沿用现有可见来火风险模型计算每个动作的死亡概率；把移动计划、距离推进、访问次数和入点效果的效用，以及战斗后的堡垒驻留、到点任务/采集和下一Tick原位置事件代价，按模型存活分支计入。死亡分支保留普通动作成本，不虚构移动成功、回血或任务完成。

攻击在死亡前结算，因此保留即时攻击贡献和击杀奖励的估值；死亡扣60、固定死亡项及已推广的联合动作估值不变。联合攻击分支中的驻留奖励也按各分支是否存活处理。预测中的零存活概率只是当前风险模型的结果，不代表读取了敌方本Tick动作；当实验性概率风险模型给出部分存活机会时，仍按该机会保留部分推进价值。其他实验组合未因此得到整场验证。

为后续合法复盘，在本车decision日志增加alive、protected、public_missions和initial_spawn。这些字段均来自本车当前感知或本车已确认的历史，不新增订阅、不合并四车记忆，也不读取测试配置。

先验证致死移动、存活/出生保护/第一阶段与部分存活机会边界，再以同一冻结程序做三类对手及新地图的完整配对。只有最终分数、任务或第一次数改善才可作为推广依据；动作从move变attack或名义伤害增加不能单独算成功。

## 确认复活后重新选择公共任务路线

新日志的当前对手16场中，113个本车存活且受出生保护的Tick全部提交MOVE，没有发现原地浪费。map54617 C最后仍未完成本车感知公开的reach任务(6,22)，最终位于(19,2)、D455、资源50、两任务，36.15分。它长期仍有一份记忆资源，且D未达到旧坐标优先实验要求的620；这只是候选机会，不能据此直接声称可追回5分。

新增独立参数respawn_task_route=false。仅第二阶段后三分之二、地图至少75%已探索、上一帧本车阵亡且本帧存活并受保护、过去32Tick历史连续时，使用实际复活坐标重新评估未完成公开reach任务。把任务5分除以本车当前加权路线成本加1，与过去32Tick本车调整后净对抗分增量除以32比较；若任务估计速度更高，暂缓主动追击目标，保留对已知资源、其他有限目标和即时攻防的原比较。

历史对抗速度包含死亡扣除及500分上限，只是一种过去表现的估计，不保证未来重复；路线成本也不是已证明的实际耗时。该实验不预知复活点、不从席位猜出生点，使用本帧已确认位置，因此不依赖未知的未来占位。选择的公开任务在完成、撤销、已知不可达、剩余Tick不足、再度阵亡或换场时清除；reset同时清空路线状态。第一阶段、前期、漏历史或没有确认复活时保留原行为。已知资源可以优先于所选任务，不因承诺任务而丢弃资源事实。
