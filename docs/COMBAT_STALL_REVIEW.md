# 连续观测下的追击与防御僵持

记录日期：2026-10-23。开发时四车独立运行，正式只控制本队一车。以下判定均可从对应车辆自己的感知历史重现，不合并各车地图或读取对手私有决策。

## 观察与原因

上一轮四车基线interior59341中，A/D在20HP时连续防御数百Tick：每车自己看到的对手都停在两格外、保持20HP、防御标记为真。当前估值仍假设所有可射击敌车必开火，移动或攻击都按致死处理，防御因此长期胜出。

B/C各自看到另一辆车在同一个四格环中移动，本车逐格追逐，双方长期保持斜对角。追击目标虽然是射击位置，但两车同时移动导致位置不断变化，没有得到实际射击机会。

这些现象说明当前估值存在值得检验的缺口，不代表可以无风险增加固定数量的伤害或得分。

## 追击循环实验

`break_pursuit_cycles=true`（已通过后续配对并推广，原策略可显式false）。只在第二阶段前五分之一以后、仍有下一Tick、无已知资源、当前目标为交战点且无当前射击机会时考虑。自己的连续历史必须确认2–8Tick的一个闭合移动周期：本车和同一可见敌车每Tick都移动一格，最终各回原位，双方HP、本车资源、对抗累计值和任务完成项均未变化。不能用丢帧或不可见期间补猜周期。

符合条件时给等待一Tick增加有限价值；当前伤害和事件危险仍完整计入。暂停后的静止记录会打断完整移动周期，不能连续无限等待。用本车与敌车坐标的自然顺序打破同时等待的对称，不依赖席位名称、地图ID或反例坐标。

## 防御僵持风险实验

`standoff_fire_risk=false`。仅在第二阶段前五分之一以后、对抗累计值不足500、没有洁身自好反伤事件时，考虑降低必开火假设。需要连续四帧本车位置/HP/资源/D/任务项都不变，同一可见敌车的位置/HP也不变、持续防御且无出生保护。

条件满足时，下一Tick开火采用25%的启发式概率。它不是实测校准概率，也不保证对手继续防御。最多对三个可见威胁枚举八种开火组合；按各动作的伤害、易伤倍率计算死亡概率，并逐分支按“攻击贡献与奖励先加、死亡扣60后最低0”估值。因此不能把平均伤害低于HP解释成不会阵亡。未满足条件的威胁保持原有保守估值；不修改感知提供的权威D，也不伪造其他车状态。

目前以原有攻击/防御倾向估计己方攻击贡献及收尾奖励，和来火分支并非完整联合对手动作模型，仍为本地启发式。必须通过最终比分和退步案例验证，不能把概率计算本身当作收益。

单元回归确认20HP对20HP的可获利收尾会比较攻击，20HP对100HP的低价值攻击仍会因致死概率而选择防御；丢帧、已有进展、非持续防御、反伤事件、第一阶段及满额对抗分保留原行为。含追击条件回归共95项汇总检查通过。
