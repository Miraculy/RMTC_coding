# 阶段一 e075 验证摘要（2026-10-25）

本文件记录正式包阶段一默认算法 **e075** 的验证范围、结果与复现方式；逐图原始数据与更完整的实验过程存档于仓库外维护目录 `../analysis_opt_order_20261025/`（`REPORT.md`、`INSTALL_LOG.md`、`versions/e075/`）。

## 1. 改动

`src/rmtc_bot/src/stage1_subgoal.cpp`：未知区域侦察候选的排序由

```
marginal_view / (distance + 1)^0.85
```

改为

```
marginal_view / (distance + 1)^0.75
```

含义：更偏好近处、可快速兑现的视野收益，减少长距离侦察。

启用方式：`src/rmtc_bot/src/node.cpp` 中 `stage1_resource_route`、`stage1_joint_coverage`、`stage1_subgoal_risk` 默认值均为 `true`，因此 `./run_contestant.sh A 1` 无需额外参数即使用 e075。回退：

```bash
./run_contestant.sh A 1 -p stage1_resource_route:=false \
  -p stage1_joint_coverage:=false -p stage1_subgoal_risk:=false
```

## 2. 验证方法

- 裁判：主办方练习裁判（真实裁判逻辑），第一阶段默认节奏 100 ms × 100 Tick、A 席位；
- 对照：同一地图、同一裁判流程下，冻结的基线二进制与 e075 二进制逐图配对运行；
- 基线：Codex v4-order-v2（19 张 20×20 开发图逐图一致复现，均值 35.6842、满分 4）；
- 独立图集：用 `stage1_eval.generate` 从练习裁判模板生成，共 4 组各 30 张、18×18、25%/30% 障碍（种子段 20001/30001、40001/50001、60001/70001、80001/90001）；
- 复跑确定性：同一二进制在新独立集上复跑 30/30 图分数完全一致；
- 时延：记录每局决策耗时的 P95。

- 139 局中仅 6 张图决策改变：5 张提升（+2~+8），1 张 −2，其余 133 张逐图不变；
- 唯一退步为 `new30-30008` 与 `g30-90013` 各 −2（不同图集），均未超过“单图 −2”门槛，且均非满分图；
- 时延：低负载（1 worker）19 开发集最大单图 P95 23.67 ms，独立集 19.3–20.9 ms，均 ≤25 ms；3-worker 高负载时曾出现单图 25.1–26.5 ms 的负载噪声。

## 4. 结论与边界

- e075 在 25%/30% 障碍地图上以极低决策扰动取得稳定正收益，作为阶段一默认算法；
- **未重新验证** 40% 密集图（属次要参考），也未对阶段二做行为回归；
- 独立图集来自练习模板（18×18），开发图为 20×20；两者均应视为练习场景，正式赛场条件以主办方公告为准。
