## 1. 参考控制器与推演器的误差

新增`Planner::stage1_reference_snapshot()`：复制控制器并关闭一阶段研究开关，保留目标等内部记忆。修订副本subgoal参考首步，使用该快照。它代表“在当前本车历史上关闭实验后的反事实续跑”，不是假装知道另一辆基线车的隐藏历史。

离线工具在215图的Tick20/40/60共645个状态比较续跑。完整快照645/645与原控制器直接复制的续跑逐动作、最终R相同；原始全程的215个最终R也全部复现历史基线。重建空控制器改变9条后续轨迹、3个首步、4个最终R，重建相对保留记忆的R差值为−20到+10。因此记忆偏差真实存在，但该抽样上不够解释全部严重退步。

进一步把旧subgoal-v4的简化推演器放到同一开发环境中，各自只获得自身方形视野。最终版本严格使用相同的基线首步，再比较余下控制逻辑：

- 645个状态中，161个最终R不同；46个误差绝对值超过10R。
- 平均绝对误差3.4729R，平均有符号误差+1.3023R，范围−50R到+50R。
- 未对齐首步的初版数据仍保留（163个不同、47个超过10R）；结论使用后续严格对齐版本。

这隔离的是后续控制策略近似误差，**不包含8张假想图的先验失配**。也没有直接证明候选与参考的相对误差必然同样大，不能把这组误差当成已校准风险置信区间。当前10R样本内门槛不能宣称实战最多退2分。精确续跑现在用于离线诊断；在线8场景仍是简化推演，尚未替换为完整快速控制器。

## 2. 五项开发消融

1. **cluster-v1**：从已知可达空地中选有新增方形视野的位置，使用视野交并比和已知BFS距离分组，每组保留便宜入口、较大覆盖、已知资源出口代表；其余联合规划保留。原15满分升到2，但全图均分和尾部没有通过。说明只压缩观察候选不足，且这种压缩可能丢掉有用的未来连接；未证明是具体退步的唯一原因。
2. **beam-v2**：已知DP、最近邻和既有路线作种子，宽16/深4，资源序列中至多一次显式观察，并用剩余资源完整收尾评价前缀。资源间仍用带未知惩罚的预测距离。全开发最差退16分；增加搜索没有修复未来收益预测。warm路线对失效资源位置的处理在v3补了“最多一个空观察点”的约束，因此v2与v3并非纯单一通路开关消融。
3. **safe-v3**：资源路线也只经过已确认空地；未确认通路的资源仍保留在World记忆，只从本轮可执行路线排除，通过观察继续发现通路。该限制降低了整体表现，不能认定“路径更确定”就能提高总得分。
4. **retrieval-v4**：在v3上，以已知墙的几何最短路估计每个预测未知资源的往返取回成本，沿路线同一未知格只计一次，取回与已知采集共同消耗预算。未知墙仍作为乐观预测，非实际已知；独立往返又可能高估可合并采集的成本。本轮没有得到稳定收益，不能把新成本称为准确真实代价。
5. **incumbent-v5**：回到更强的旧联合v17，只对仍在局部范围的未采资源目标增加10R改道优势门槛，并保留以当前目标起步的路线种子。10R是一个普通资源的启发式门槛，不是概率误差界，也不是重复扣除的物理移动成本。178图相对正式增分、10图退步，但原15出现−4和复杂图−10，仍失败。

## 5. 下一步收敛方向

本轮没有理由把更多探索权重、硬性安全路约束、或更深Beam直接写进正式入口。下一轮先实现和验证**快速、忠实的阶段一参考续跑**：应在同一合法历史和后续观测序列上复现目标记忆、资源年龄、路径代价、决策顺序，再衡量时间预算内可以评估多少分支。复用本轮校准器对候选/参考相对差值校准，而不只比较单条预测的绝对误差。

随后再测试少量可以中途根据新观测修正的资源/观察分支，把未知拓扑误差与后续控制误差分别测量。是否采用聚类、Beam或迟滞仍由增分与尾部指标决定。这个方向尚未实现，不能宣称修正推演器一定提高比赛成绩。
