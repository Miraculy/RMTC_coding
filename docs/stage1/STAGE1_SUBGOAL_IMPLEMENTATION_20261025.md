# 一阶段入口风险与失败回退收益实现（2026-10-25）

已将网络研究中优先的“入口风险＋探索失败后的剩余资源收益”实现为隔离原型，完成5个版本、各215张开发图的筛选。**尚未通过复杂图稳定性，整体没有优于上一联合研究版，不替换正式入口。** 正式src/run_contestant.sh及994515d8保持不变。

## 实现范围与数据边界

新目录`experiments/stage1-subgoal-20261025`基于joint v17清理版，新增`stage1_subgoal_risk=false`，核心和ROS节点默认均关闭，正常colcon由COLCON_IGNORE排除。本轮仅针对20×20、单车静态、100Tick一阶段；其他场景回到已有控制器。

1. 候选宏动作包含参考控制器的一步、联合规划提出的资源/观察目标、最多3个已知资源方向和3个分开的观察点。实际固定宏动作只走本车已经观察为空地的格子，每Tick仅发一条合法动作。
2. 对已知空地图求资源回收值：最多12个剩余资源时为预算子集精确求解，更多时为多起点贪心可行下估计。计算的是“固定宏动作执行后，再按回收路线收集”的条件收益，不是当前策略最终必得分数。独立枚举测试核对该子问题。
3. 从本车已知空地、墙和资源生成8个完整假想图；已知格不能改动，剩余资源数值依据公开200R/12普通+4高值及本车确认采集更新。每个模拟控制器只看到自己方形视野及记忆。全图样本仅供内部模拟环境使用，绝不写入真实World。
4. 在已知空地图上检测桥边。若候选需要通过桥进入分支，再构造“该分支没有额外未知出口”的压力图，只封闭未观察格并保持样本资源池；参考路线和候选在同一压力图比较。已知图中的桥不等于真实地图的死胡同，压力图不赋予真实发生概率。
5. 常规预测得分为平均模拟R−最大两项正向对照损失的均值−0.25×已知失败回收值损失；若任一常规场景或额外压力图比参考少超过10R则不选该候选。这里的10R是模型内筛选条件，不能当作真实比赛最多掉2分的证明。未来参考由简化后续策略近似，不是原程序完整反事实重放。
6. 全部资源已知或本车已收R＋已知可执行回收值达到190时，尝试已有认证精确收尾；获准后保留已认证路线。其执行承诺只在对应单车静态前提下解释。

借鉴来源：[LSP, CoRL2018](https://proceedings.mlr.press/v87/stein18a.html)、[AIPPMS, ICAPS2020](https://ojs.aaai.org/index.php/ICAPS/article/view/6645)、[Risk-Averse Stochastic Orienteering, 2019](https://dergipark.org.tr/en/download/article-file/816644)。本原型没有训练原论文的学习器，也不是完整POMCP树搜索，不继承其理论保证。

## 这轮发现

- 正确算出已知回退子问题，不代表对未知区域的最终收益估计准确；有限场景、未知地图分布与简化后续策略会产生误差。
- 固定少量假想图减少了抽样变化，却可能长期偏向假想资源热点；v2/v3原图seed3出现−6，故不采用该变体。
- 窄入口失败检查能工作，但对没有已知桥结构的错误早期改道约束有限。v4在1000/30%的seed1019上32→20，轨迹显示早期数次改变访问区域后，后续逐步跟随参考也无法追回遗漏资源。
- 给后续策略补充年龄、目标和重复访问因素并未自动提升结果；v5仍有−12反例，最大P95 32.305ms超过25ms。保留其源码和结果，恢复v4用于功能核对。
- 独立回归还发现旧联合缓存的边界异常：零资源、零障碍且缓存未初始化时对null诊断调用value。新副本已先检查有效缓存，再读取；正式版没有启用这段实验逻辑。原失败日志完整保留。

## 后续重点

应先量化推演误差：在同一合法观察状态下，对比样本预测的后续收益、通道成本和失败损失，与自建图中按合法感知执行的分支结果；尤其验证参考后续策略能否复现原控制器。模型校准后再扩大其改道权限。当前证据不支持靠继续调整风险权重替代这项核对。

入口风险模块实现、失败版本和反例已保存，但复杂图稳定满分目标未完成；不推广、不使用预留确认图来调参。
